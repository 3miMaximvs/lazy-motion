Lazy Motion 0.2.0 ajoute les mises à jour depuis GitHub Releases.

- Recherche automatique à l’ouverture et recherche manuelle dans les réglages.
- Notification lorsqu’une nouvelle version stable est disponible.
- Installation à la demande, vérification SHA-256 et sauvegarde de la version précédente.
- Les outils Cascade, Durée commune et Point d’ancrage restent disponibles hors connexion.

Après installation d’une mise à jour, enregistrez votre projet et redémarrez After Effects.

Compatible Windows et After Effects 2026 / 26.x. Première installation : télécharger le ZIP, son fichier SHA-256 et `Installer-Lazy-Motion.ps1` dans un même dossier. Exécuter le script une seule fois, After Effects fermé. Les mises à jour suivantes passent par le panneau.

Cette version personnelle utilise le chargement des extensions CEP locales non signées ; le script active le mode développeur CEP 12 pour le compte Windows courant.
